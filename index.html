Not a cloud. A crowd.

A normal website is a computer somebody else owns. These pages are different: the address is a key, the hosts are the readers, and the only fixed point is a tracker whose entire job is to introduce browsers to each other.

Addressed by a key

A page's address is an ed25519 public key. Only the holder of the matching secret can publish to it; everybody else can verify that what arrived is what was signed.

Served by its readers

Every visitor seeds what they just read, and seeds it again on every return. Close the author's laptop and the page stays up for as long as one tab, anywhere, is open.

Updatable

Publish version two to the same address. The signed pointer is gossiped every three seconds, so everyone watching picks it up almost at once, and an older version can never be replayed.

Nothing to install

One HTML file in any modern browser. WebRTC carries the data between browsers; a WebSocket tracker only introduces them. Content never passes through a server.

How a page with no server works

The semantics of BEP 46, signed, owner-only, sequence-numbered updates, with the one piece a browser cannot have, the BitTorrent DHT, replaced by a WebRTC rendezvous swarm.

01

A file becomes a torrent

One self-contained HTML file is seeded over WebTorrent. Its infohash is the fingerprint of its exact contents.

02

A key becomes an address

The owner signs a tiny pointer, sequence number plus infohash, with an ed25519 key. The public key is the address: bep46:<64 hex>.

03

Peers meet at sha1(key)

Everyone interested in an address joins a WebTorrent swarm named after the key. A WebSocket tracker introduces them; from then on they talk directly over WebRTC.

04

Readers become hosts

The pointer is gossiped every three seconds. Each browser fetches the bytes from whoever has them, verifies them, renders them in a sandboxed frame, caches them, and seeds them again on every visit.

{
  "k":   "<64-hex ed25519 public key>",   // the address
  "seq": 3,                                // strictly increasing
  "ih":  "<40-hex infohash>",             // the current bytes
  "sig": "<128-hex signature over seq‖ih>"
}

The whole protocol fits in this record. Peers drop any pointer whose signature does not verify under k, and any whose seq is not greater than the one they already hold. The accounts and the social network use the same idea with richer records: per key, the highest sequence number wins, and deletions are tombstones that stay.

Build on it

Everything here is plain files. Fork the repository, switch on GitHub Pages, and you have your own copy of this site, the publisher, Catwalk and the registry. No build step, no CI, nothing to deploy.

import WebTorrent from './accounts/vendor/webtorrent.min.js';
import { configureBrowser } from './accounts/src/env-browser.js';
import { Directory, webStorageStore } from './accounts/src/directory.js';
import { Accounts } from './accounts/src/accounts.js';
import { Replica } from './accounts/src/replica.js';
import { WebTorrentTransport } from './accounts/src/transport-webtorrent.js';

configureBrowser();                        // nacl + scrypt, from the two vendored scripts
const directory = new Directory({ store: webStorageStore(localStorage) });
const accounts  = new Accounts({ directory });
const transport = new WebTorrentTransport({ client: new WebTorrent({ dht: false, lsd: false }) });
new Replica({ directory, transport }).start();   // gossip with every open copy of the page

await accounts.register('mittens', 'catnip2004');
const me = await accounts.login('mittens', 'catnip2004');   // decrypts the key, locally

That is the whole Swarm Registry, minus the HTML. The directory is a replicated map that converges whatever order records arrive in; the replica gossips it as a BEP-10 extension; the transport is a WebTorrent swarm that carries no torrent at all. Catwalk adds a second map keyed by record id, and gets a social network.

The fine print

A network with no server has no one to lie for it. These are the limits, straight from the README.

Durability is social

A page or a record exists for as long as someone who has it comes back online, and browsers evict storage. If you need more, keep one always-on headless replica: it is a mirror, not an authority, and cannot forge or roll anything back.

Passwords can be guessed offline

A sealed key is public by construction. scrypt at 215 makes every guess cost 32 MiB of memory, which turns a short password into a lost account, not a safe one. There is no reset, because nobody holds anything that could reset it. Where this goes next: a database you share only with your friends.

Trackers are the fixed point

Browsers cannot find each other on their own; a WebSocket tracker introduces them. The project runs its own and every app lets you enter yours. The tracker sees an infohash and a WebRTC offer, never content.

Not mainline BitTorrent

It keeps the semantics of BEP 46, not the wire format of the DHT, so it does not interoperate with mainline clients. It is a network among the browsers running these pages.
