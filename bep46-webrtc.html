BEP-46 / WebRTC

Mutable torrents, entirely in the browser. The channel ID is sha1(publicKey) — the same target BEP-46 uses in the DHT — but the signed pointer is gossiped over a WebRTC rendezvous swarm instead of the mainline DHT. Owner-only updates, ed25519-signed, sequence-numbered.

2 · CREATE & PUBLISH

Seed content, then point your address at it

Publishing a new version is always two clicks: Create torrent (seeds the chosen file), then Publish new version. Selecting a different file re-arms Create — you must Create again before you can Publish it.
seq — seeding 0 peers
Each publish increments the sequence number, re-signs, and gossips the new pointer. A heartbeat keeps re-broadcasting it every 3 s, so a follower that joins after a publish still syncs. Keep this tab open to keep seeding.
